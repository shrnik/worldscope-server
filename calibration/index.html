7AI landmarks▸

A vision LLM (HF Inference Providers) spots fixed landmarks in the frame, SAM3 segments them to exact pixels, and Wikipedia supplies info — including coordinates, so a landmark can become a calibration pair in one click. Small features are segmented twice automatically: a full-frame pass finds them, then a native-resolution crop around the match refines the pixels. Needs the HF token from Settings.

8Agent auto-calibrate▸

An open VLM (HF Inference Providers) runs the whole calibration autonomously: seeds with GeoCalib, looks at the frame, pulls OSM / Wikipedia coordinates, segments exact pixels with SAM3, adds pairs (incl. sun/moon if the capture time is known), solves, and visually verifies. Needs the HF token from Settings; every detection appears live on the image.
